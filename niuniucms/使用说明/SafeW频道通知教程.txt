SafeW频道通知教程（一步一步照做）

一、功能说明
1）把机器人拉进频道/群后，系统会自动识别 chat_id 并保存
2）网站有新视频时，定时自动推送到已绑定频道/群
3）支持多机器人（机器人池），可按启用状态统一调度
4）后台可设置同步/推送间隔分钟，无需每次改 cron
5）消息支持：标题、状态、热度、简介、观看地址、标签池、菜单按钮

--------------------------------------------------
二、准备工作
1）先在 SafeW 的 @BotFather 创建机器人，拿到 BOT_TOKEN
2）把机器人拉进目标频道/群，并设置为管理员
3）在频道/群里先发一条消息（用于自动识别 chat_id）

SafeW Bot API 文档：
https://docs.safew.org/bot-api/

--------------------------------------------------
三、首次绑定（自动获取频道ID）
推荐执行命令（多机器人统一脚本）：
php /www/wwwroot/sesewu3.eu.cc/niuniucms/cli/safew_sync_all.php 100 --force

兼容旧命令（单机器人）：
php /www/wwwroot/sesewu3.eu.cc/niuniucms/cli/safew_sync_updates.php "你的BOT_TOKEN" 100

返回示例：
{"ok":true,"updates":1,"saved_chats":1,"last_update_id":1775...}

说明：
- ok=true：接口调用成功
- saved_chats=1：成功识别并保存了一个频道/群

--------------------------------------------------
四、手动测试推送
推荐执行命令（多机器人统一脚本）：
php /www/wwwroot/sesewu3.eu.cc/niuniucms/cli/safew_push_all.php 10 --force

兼容旧命令（单机器人）：
php /www/wwwroot/sesewu3.eu.cc/niuniucms/cli/safew_push_worker.php "你的BOT_TOKEN" "https://你的域名" 10

返回示例：
{"ok":true,"sent":3,"failed":0,"last_push_ts":1775...,"rows":3}

说明：
- sent：成功发送条数
- failed：失败条数
- rows：本次扫描到的新视频条数

--------------------------------------------------
五、正式定时任务（推荐）
推荐两个任务（统一多机器人）：

任务A：每分钟触发同步脚本（实际执行频率由后台“同步间隔(分钟)”控制）
php /www/wwwroot/sesewu3.eu.cc/niuniucms/cli/safew_sync_all.php 100 >> /www/wwwlogs/safew_sync.log 2>&1

任务B：每分钟触发推送脚本（实际执行频率由后台“推送间隔(分钟)”控制）
php /www/wwwroot/sesewu3.eu.cc/niuniucms/cli/safew_push_all.php 10 >> /www/wwwlogs/safew_push.log 2>&1

后台间隔配置位置：
SafeW通知 -> 同步间隔(分钟) / 推送间隔(分钟)

--------------------------------------------------
六、宝塔计划任务报“root被加锁”怎么办
如果宝塔添加计划任务时报：
/var/spool/cron/crontabs/root 文件被加锁

请改用系统级 cron.d（不走宝塔弹窗）：

1）创建任务文件（示例）
文件：/etc/cron.d/nncms_safew
内容：
SHELL=/bin/bash
PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
* * * * * root flock -xn /tmp/nncms_safew_sync_all.lock -c '/usr/bin/php /www/wwwroot/sesewu3.eu.cc/niuniucms/cli/safew_sync_all.php 100' >> /www/wwwlogs/safew_sync.log 2>&1
* * * * * root flock -xn /tmp/nncms_safew_push_all.lock -c '/usr/bin/php /www/wwwroot/sesewu3.eu.cc/niuniucms/cli/safew_push_all.php 10' >> /www/wwwlogs/safew_push.log 2>&1

2）重启 cron
systemctl restart cron

--------------------------------------------------
七、日志查看
同步日志：
tail -n 50 /www/wwwlogs/safew_sync.log

推送日志：
tail -n 50 /www/wwwlogs/safew_push.log

如果 sent=0 且 failed=0，多半是当前时间段没有新视频，不是故障。

--------------------------------------------------
八、常见问题
Q1：返回 Bad Request: invalid file_id
A：图片发送被接口拒绝，系统会自动回退为文本消息，不影响推送。

Q2：收不到频道消息
A：确认机器人已在频道里，且是管理员；频道里先发一条消息后再执行 sync。

Q3：推送重复
A：系统已按 vid+时间做去重。若你手动改库时间或清日志，可能重新推送。

Q4：新增机器人后要不要再加 cron？
A：不用。后台新增并启用机器人后，统一脚本会自动按机器人池执行。

--------------------------------------------------
九、安全建议（非常重要）
1）BOT_TOKEN 不要发给他人，不要截图外传
2）若怀疑泄露，立刻在 @BotFather 重置 token
3）重置后同步修改所有定时任务中的旧 token
